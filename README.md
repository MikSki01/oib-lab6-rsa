# ЛР6 — Асиметричне шифрування RSA

Дисципліна: Основи інформаційної безпеки, група МІТ-21.

Рішення `Lab6.Rsa.slnx` (.NET 10, C#) складається з двох консольних проєктів:

| Проєкт | Що робить |
|---|---|
| `RsaCipherApp` | шифрує й розшифровує дані RSA-2048; пара ключів зберігається у пам'яті (завд. 1) та у файлі-контейнері (завд. 2) |
| `RsaExchangeApp` | зберігає відкритий ключ у `<прізвище>.xml`, шифрує вітання відкритими ключами інших студентів і розшифровує отримані (завд. 3–4) |

## Запуск

```bash
dotnet run -c Release --project RsaCipherApp
dotnet run -c Release --project RsaExchangeApp
```

## Висновки
- RSA асиметричний: відкритим ключем шифрують, закритим розшифровують.
- Відкритий ключ (`*.xml`, лише публічна частина) вільно поширюється; закритий лишається в таємниці.
- Контейнер дозволяє повторно використовувати пару ключів. Іменовані контейнери CSP є лише у Windows, тому тут роль контейнера виконує файл.
- Асиметричне шифрування дозволяє обмінюватися таємними повідомленнями без попереднього спільного секрету.
